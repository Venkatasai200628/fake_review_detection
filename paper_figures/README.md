# Paper figures — Fake Review Detection via Visual Forensics

Generated by `fake_review_dataset_v6/code/make_paper_figures.py`. Every number comes from
files already in `fake_review_dataset_v6/out/` (nothing is invented). Each figure is saved as
**PNG (300 dpi)** for drafts and **PDF (vector)** for LaTeX — same filename, different extension.

Regenerate everything:

```bash
cd fake_review_dataset_v6/code
python make_paper_figures.py        # ~2 min (one feature-build pass for fig10-12)
```

## Notes for the write-up

- fig04, fig05, fig10-12 come from **the same** trained fusion model and photo-grouped splits, so they can be cited together.
- fig07's McNemar p-values (each < 1e-11) are in `out/model_comparison/paper_models_on_our_data.csv`, column `mcnemar_p_vs_ours`.
- fig13's CI values come from the independent verification run (`code/verify_results.py`, log: `code/verify_results_run.log`), which also confirmed: no feature leakage (shuffled-label ROC-AUC ≈ 0.509) and seed stability (test accuracy 0.930–0.932).
- All figures are generated with the seaborn `colorblind` palette, so they stay readable in greyscale and for colour-blind readers.
